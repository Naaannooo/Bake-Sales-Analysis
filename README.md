
# Excel Data Analysis Project

## Overview

This project analyzes a dataset using Microsoft Excel, from data cleaning and analysis to visualization and dashboard creation.

## Tools

* Microsoft Excel
* Data Cleaning
* Pivot Tables
* Charts
* Dashboard

## Project Steps

1. Cleaned and prepared the raw data.
2. Created analysis tables to identify key insights and priorities.
3. Created charts to visualize the results.
4. Built an interactive dashboard to summarize the findings.

## Key Insights

* Identified the most important trends and categories in the dataset.
* Compared key metrics using tables and charts.
* Summarized the main findings in an easy-to-understand dashboard.
